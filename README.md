    <td align="left" valign="top"><b>What it is:</b> A comprehensive, Python-powered security scanning wrapper that seamlessly combines the raw power of <b>Nmap</b> (network mapping) and <b>SQLmap</b> (vulnerability detection) into a beautifully formatted, automated CLI experience.<br><br><b>Why I built it:</b> To streamline ethical hacking and penetration testing. Instead of juggling complex terminal commands, you can instantly launch predefined scan intensities (<i>Easy, Medium, Hard</i>) to automate reconnaissance and regular security audits.<br><br>⚙️ <b>Tech Stack:</b> Python, Bash, Nmap, SQLmap.</td>
    <td align="left" valign="top"><b>What it is:</b> An ultra-lightweight, zero-bloat systemless ad-blocking module for rooted Android devices (<i>Magisk, KernelSU, KernelSU Next, SukiSU, APatch</i>). It kills ads, trackers, and telemetry globally at the DNS level by optimizing the <code>/system/etc/hosts</code> file.<br><br><b>Why I built it:</b> To provide uncompromising mobile privacy <i>without</i> battery-draining background apps. It features a built-in WebUI right on your device, allowing you to switch between 7 curated blocklists (<i>StevenBlack, hBlock, HaGeZi</i>), add your own allow and block rules, and update with a single tap.<br><br>⚙️ <b>Tech Stack:</b> Shell, HTML/CSS/JS (WebUI), Android Root (Magisk, KSU, APatch).</td>
